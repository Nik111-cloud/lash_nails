# Мобильная производительность — 7 октября 2026

## Исходный PageSpeed

[Отчёт владельца](https://pagespeed.web.dev/analysis/http-www-estetika-ufa-online/t6o773dbm1?form_factor=mobile): мобильная производительность **67**, FCP **3,2 с**, LCP **6,5 с**, Speed Index **5,6 с**, TBT около **30 мс**, CLS **0**. LCP-элемент — фотография первого экрана `img1.avif`.

В начале загрузки скачивались второй скрытый слайд, фоны всех услуг и фотографии далеко ниже первого экрана. На медленном мобильном соединении они конкурировали с первым фото. Также загружались внешняя таблица Google Fonts и несколько файлов шрифтов.

## Изменения

- Добавлен preload фотографии первого экрана с высоким приоритетом.
- Остальные фото, фоны услуг и карта загружаются при приближении к видимой области. Наблюдение начинается после отрисовки первого фото или сразу при прокрутке пользователя. Нет фиксированной задержки, препятствующей прокрутке.
- Скрытый второй слайд получает изображение при переключении. Неактивные мастера загружаются при выборе.
- Для отключённого JavaScript оставлены `noscript`-изображения, фоны и карта.
- Golos Text и Playfair Display теперь размещены на сайте: два WOFF2-файла вместо внешней CSS-таблицы и нескольких наборов. Сохранены используемые начертания, русские и латинские символы, знаки цены и пунктуация. Лицензии находятся в `fonts/`.
- Фотографии сохранены побайтно в исходном качестве; раскладка первого экрана и калькулятора визуально проверена.
- Мерцание верхней кнопки «Записаться» восстановлено. При системной настройке уменьшения движения анимация отключается.
- CTA первого экрана сохранён: «Выбрать время онлайн». Метрика, Вебвизор, цели и переход в DIKIDI сохранены.

## Замеры и ограничения

Lighthouse 13.5.0, мобильная эмуляция, локальный HTTP-сервер, холодный профиль Chrome. Два финальных запуска дали **92** и **98** баллов.

| Показатель | До, локально | Финальный запуск 1 | Финальный запуск 2 |
|---|---:|---:|---:|
| Производительность | 89 | 92 | 98 |
| FCP | 0,91 с | 1,23 с | 1,14 с |
| LCP | 3,83 с | 3,07 с | 2,40 с |
| TBT | 22 мс | 163 мс | 46 мс |
| CLS | 0,0011 | 0 | 0,00014 |
| Передано при замере | 1,07 МиБ | 0,50 МиБ | 0,50 МиБ |

Объём передачи сократился примерно на **53%**. Разброс результатов сохраняется из-за нагрузки компьютера и стороннего скрипта аналитики. FCP в локальном замере стал немного выше; основной выигрыш — LCP и объём начальной загрузки.

**Эти баллы не являются повторным PageSpeed опубликованного домена.** Локальная сеть, сжатие ответов сервера и условия эмуляции отличаются. В частности, PageSpeed использовал свой коэффициент замедления CPU. Для сравнения условий «до» и «после» здесь используется отдельный локальный исходный замер, а не прямое сопоставление 67 с 98.

Во время локальных измерений библиотека Метрики загружалась и выполнялась; запросы статистики блокировались, чтобы не создавать тестовые просмотры в рабочем счётчике. На рабочем сайте такого блокирования нет.

Функциональные проверки прошли на восьми размерах экрана, включая телефон 320 px и горизонтальную ориентацию. Проверены отложенная загрузка, изображения, калькулятор (48 комбинаций), оба слайдера, просмотр фото, возврат фокуса, переход к мастеру, возврат со страницы записи и три цели. Отдельно проверена прокрутка при ещё не загруженном первом фото и работа без JavaScript.

## Публикация

Новые файлы шрифтов обязательно отправить вместе с HTML, CSS и JS:

```bash
git add index.html styles.css site.js fonts/ scripts/ tests/ .gitignore PERFORMANCE.md REVIEW.md
git commit -m "Оптимизировать мобильную загрузку лендинга"
git push origin master
```

Дождаться успешной публикации GitHub Pages и заново запустить PageSpeed в режиме **Mobile** на опубликованном URL. Устойчивая оценка 90+ на домене подтверждается только этим повторным замером. Для измерения реального HTTPS-сайта предварительно должен корректно работать сертификат домена.

## Повторяемая проверка

Файлы уже готовы к публикации: запуск сборки шрифтов не требуется. Для повторного измерения установить инструменты в игнорируемую папку:

```bash
pnpm --dir .performance add lighthouse chrome-launcher
python -m http.server 4173 --bind 127.0.0.1
```

В другом терминале:

```bash
node tests/performance.mjs http://127.0.0.1:4173/ performance-result
```

Скрипт сохранит JSON и HTML отчёта. На этой машине он использует установленный Chrome. Для пересборки файлов шрифтов приведены отдельные инструкции в `scripts/subset-fonts.py`; зависимости сборки не нужны посетителям сайта.

Подход к приоритету первого изображения соответствует [рекомендациям web.dev по LCP](https://web.dev/articles/optimize-lcp).
